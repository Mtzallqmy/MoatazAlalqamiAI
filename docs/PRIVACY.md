# Privacy Policy — Moataz Alalqami AI

## 1. البيانات المحفوظة محليًا
كل شيء يُبقي على جهازك: المحادثات، الإعدادات، مفاتيح API (مشفرة)، سجلات الوكيل والاستخدام، مشاريعك. لا يوجد خادم خاص بالتطبيق ولا جمع بيانات.

## 2. ما يُرسل لمزودي الذكاء الاصطناعي
رسائلك تُرسل فقط للمزود الذي اخترته أنت في الإعدادات، عبر URL الذي أدخلته أنت. نحن لا نتوسط في أي طلب ولا نخزن محتوى محادثاتك لدى أي طرف ثالث.

## 3. مفاتيح API
تُحفظ مشفرة عبر Android Keystore. لا تُشارك ولا تُرفع خارج جهازك تحت أي ظرف.

## 4. Telegram
البوت يستجيب فقط للمحادثات في allow-list الذي تملكه، ولا يحفظ محتوى رسائلك على أي خادم وسيط.

## 5. Analytics وAdvertising
لا يوجد تتبع ولا إعلانات.

## 6. Health Checks
لا نرسل فحوص صحة دورية للمزودين؛ الاتصال يحدث فقط عند طلبك المباشر، حفاظًا على رصيدك وخصوصيتك.
